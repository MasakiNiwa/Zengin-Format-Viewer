# レコードレイアウト仕様

本ツールが採用している全銀協制定フォーマットのレコードレイアウトです。
この文書は `assets/js/formats.js` の定義から `node tools/gen-format-doc.mjs` で自動生成しています。

> **ご注意**
> 金融機関によって、ダミー領域の用途や任意項目の扱いが異なる場合があります。
> 実際にデータを提出する際は、必ず取引金融機関の仕様書とあわせてご確認ください。

## 共通事項

| 項目 | 内容 |
| --- | --- |
| レコード長 | 120 桁（バイト）固定 |
| 文字コード | Shift_JIS（JIS X 0201）の 1 バイト文字 |
| 使用可能文字 | 半角数字、半角英大文字、半角カナ、スペース、記号 `( ) - . , / ¥` |
| 属性 N（数字） | 右詰め・残りは `0` で埋める |
| 属性 C（文字） | 左詰め・残りは半角スペースで埋める |
| レコード構成 | ヘッダー(1) → データ(2)×n → トレーラー(8) → エンド(9) |

## 対応フォーマット一覧

| 種別コード | 名称 | 概要 |
| --- | --- | --- |
| `11` | 給与振込 | 従業員の給与を一括で振り込むためのフォーマットです。 |
| `12` | 賞与振込 | 賞与（ボーナス）を一括で振り込むためのフォーマットです。 |
| `21` | 総合振込 | 取引先への支払を一括で依頼する、もっとも利用の多いフォーマットです。 |
| `91` | 預金口座振替 | 売掛金などを取引先口座から引き落とすためのフォーマットです。結果ファイルの読み込みにも対応します。 |

上記以外の種別コードのファイルも読み込めますが、桁の意味は解釈せず原文表示になります。
