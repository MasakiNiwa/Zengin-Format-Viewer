適用業務およびレコード・フォーマット」令和元年 12 月

## 共通事項

| 項目 | 内容 |
| --- | --- |
| レコード長 | 振込依頼系は 120 桁、照会・通知系は 200 桁（いずれも固定長） |
| 文字コード | JIS（Shift_JIS の 1 バイト領域）または EBCDIC。本ツールは JIS に対応 |
| 属性 N（数字） | 右詰め・残りは `0` で埋める |
| 属性 C（文字） | 左詰め・残りは半角スペースで埋める |
| レコード構成 | ヘッダー(1) → データ(2)×n → トレーラ(8) を 1 組とし、最後にエンド(9) |
| 複数ヘッダー | 1 ファイルに複数の組を含めてよい（種別コードは同一に限る） |

### 使用できる文字（付録 1）

使用文字一覧に掲げられているのは、半角スペース・数字・英大文字・
カタカナ（大文字）・濁点・半濁点と、記号 `' ( ) : + , ¥ - . / ? ｢ ｣` です。
さらに項目の種類ごとに、次の制限があります。

| 項目の種類 | 使用できる文字 |
| --- | --- |
| 口座名・氏名欄 | カナ（ヲと小文字を除く）・濁点・半濁点・英大文字・数字・スペース・記号 4 種類 `( ) - .` |
| 店舗名欄 | カナ（ヲと小文字を除く）・濁点・半濁点・英大文字・数字・記号 1 種類 `-` |
| EDI 情報欄 | カナ（小文字を除く）・濁点・半濁点・英大文字・数字・スペース・記号 8 種類 `¥ ｢ ｣ ( ) - / .` |

小文字カナ（`ｧ ｨ ｩ` など）や `｡ ､ ･` は使用文字一覧に掲げられていません。
本ツールでは読み込みは行いますが、警告として表示します。
